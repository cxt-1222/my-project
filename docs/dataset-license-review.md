用户将当前使用范围限定为本地个人测试，并确认先完成非视频功能。数据库中 317 条动作文字和 1,657 条中国食物成分数据已按该范围标记并导入；中国食材记录备注明确排除公开、分发和商用授权。此状态记录的是本项目操作范围，不构成对第三方权利的独立法律结论。

> 审查日期：2026-10-27

> 本清单是正式导入前的门禁记录。`pending_review`、`unverified` 和 `restricted` 均表示不得向用户开放，也不得建立可见的 RAG 资料或媒体播放入口。

### 2.1 固定版本内的结构映射检查

对固定 commit 中的 `data/exercises.json` 做了结构检查，没有请求媒体 URL：

- 317 条动作均有非空且唯一的 `id`。
- 593 个视频 URL 和 593 个缩略图 URL 均直接位于各自动作记录的 `videos` / `thumbnails` 字段中；按 `male` / `female` 键对应，字段键集合一致。
- 276 条动作有 male 与 female 两个媒体字段，41 条只有一个媒体字段；没有动作记录完全缺少视频字段。
- 所有视频与缩略图 URL 都指向同一个 `r2.dev` 主机。此项只核对 JSON 内部关联和主机字符串，不代表访问了资源、确认其播放正常，或证明 URL 对应动作和媒体权利已获授权。

因此，当前只能确认“数据结构将媒体字段挂在具体动作记录下”，不能确认媒体内容是否确实匹配该动作，也不能确认托管方的授权链条。逐项内容核验和授权证明仍待完成。

### 3.1 食材营养数据

只读预览显示固定版本包含 1,752 条食材记录：

| 来源标识 | 数量 | 当前状态 | 处理结论 |
| --- | ---: | --- | --- |
| `中国食物成分表（第 6 版）` | 1,657 | `approved`（本地个人测试范围） | 已导入当前本地测试库；记录来源和“商用需授权”限制，不扩大为公开、分发或商用授权 |
| `usda-approx` | 95 | `pending_review` | 需要保留 USDA 来源、计量基准和适用许可证据；未确认前不开放 |

食材数据不能仅因为 `chisha` 仓库代码有开源许可就视为可再分发。每条记录必须保留来源、原始单位、每 100 克换算依据和许可状态。

### 3.2 菜谱数据

固定版本包含 238 条菜谱：

| 许可字段 | 数量 | 当前状态 | 处理结论 |
| --- | ---: | --- | --- |
| `Unlicense` | 144 | `pending_review` | 仍需确认该许可覆盖的具体菜谱内容及当前使用方式 |

菜谱还必须逐条保留来源名称、来源地址、许可字段、修订版本和食材数量。缺少来源或数量含义不清时，不得自行补全或计算营养值。

### 3.3 份量参考

固定版本包含 119 个份量 profile。份量参考只能在来源、单位和换算依据明确时用于显示估算；不能替代营养标签，也不能在依据不足时推算营养值。当前状态为 `pending_review`。

## 4. 状态与允许操作

| 状态 | 含义 | 是否可写入正式目录 | 是否可进入 RAG/用户 API | 是否可展示媒体 |
| --- | --- | --- | --- | --- |
| `pending_review` | 已发现来源，但证据或适用范围仍需人工确认 | 否 | 否 | 否 |
| `unverified` | 来源、权利人或授权链条无法核实 | 否 | 否 | 否 |
| `restricted` | 存在明确限制或许可字段缺失 | 否 | 否 | 否 |
| `approved` | 已有可审计依据，且覆盖当前用途和展示方式 | 是 | 是 | 仅限获批方式 |

当前批准范围只包括 317 条动作文字和 1,657 条中国食物成分记录。95 条 USDA 食材、238 条菜谱和 119 个份量 profile 继续隔离；图片和视频也不在批准范围内。数据库中的 `approved` 必须结合对应来源备注理解，不能外推为公开或商业用途。

## 5. 需要操作人员确认的事项

若要扩大当前本地个人测试范围，仍需逐项补充并审查：

1. USDA 近似食材的来源、单位和许可是否覆盖计划用途。
2. 菜谱的来源、许可字段、修订版本、食材数量及模糊匹配项；当前未批准菜谱继续隔离。
3. 119 个家庭份量 profile 的来源、单位和估算依据；当前不导入。
4. 每项动作视频和图片的权利人、授权链条、动作匹配、署名要求及允许链接/嵌入/下载/托管方式。
5. 如需扩大动作文字或中国食材用途，复核来源差异并重新记录允许用途；不得把个人测试状态外推为公开或商业许可。
6. 每次范围变化后，更新本机审阅锁、重新生成并审阅预览；不要将私人批准文件提交到仓库。

在上述信息完成前，系统继续保持这些扩展来源和媒体的隔离状态。
